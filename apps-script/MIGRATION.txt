LUMOS 0.8.1 기존 사용자 전환 안내

먼저 현재 게임 설정에서 저장 파일 내려받기로 진행을 보관해 주세요.
운영자가 저장 서버를 업데이트한 뒤 다음 중 해당 방법을 선택합니다.

1. 기존 복구키가 있는 경우
시작 화면 → 로그인 → 이전 복구키 계정 전환을 엽니다.
기존 아이디, 기존 복구키, 새 비밀번호, 새 비밀번호 확인을 입력합니다.
새 비밀번호는 8~128자이며 특수문자는 필수가 아닙니다.
기존 저장·아이템·챕터 진행은 같은 계정에 남습니다. 전환 후에는 새 비밀번호로 로그인합니다. 이전 복구키는 사용할 수 없습니다.

2. 기존 복구키가 없는 경우
운영자에게 계정 소유자 확인을 요청합니다.
운영자가 발급한 일회용 초기화 코드를 받은 뒤 로그인 → 비밀번호를 잊었어요를 선택합니다.
아이디·초기화 코드·새 비밀번호를 입력합니다. 코드는 발급 후 24시간 동안 한 번만 사용할 수 있습니다.
아이디만 알고 있는 상태에서는 초기화할 수 없습니다.

3. 서버 진행과 기기 진행이 다른 경우
각 여정의 챕터·구간·완료 구간 수·플레이 시간·저장 시각을 확인합니다.
각 사본을 파일로 보관한 다음 이어갈 여정을 선택합니다.
이전 버전에서 저장 시각이 없는 기록은 시각 없음으로 표시합니다. 시각을 임의로 만들어 표시하지 않습니다.
선택 전에 서버 저장을 덮어쓰지 않습니다. 연결이 실패하면 기존 기기 진행이 유지됩니다.

4. 다른 기기 또는 다른 계정
같은 아이디로 로그인하면 서버 여정을 불러옵니다.
로그아웃하면 비로그인 진행으로 돌아가며, 이전 계정 진행을 다른 계정에 자동 업로드하지 않습니다.
이전 계정의 미전송 진행은 해당 기기에 계정별로 남습니다. 같은 계정으로 다시 로그인해 서버 진행과 비교할 수 있습니다.

일반 이용자는 시트·해시·스크립트 설정을 수정할 필요가 없습니다.
