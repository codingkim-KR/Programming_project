# LUMOS 0.8.1 — 계정과 여정 보관

0.8.0의 1~6챕터 콘텐츠와 저장 스키마를 유지하며 계정·비밀번호·클라우드 저장 경험을 개편했습니다.

## 플레이어 화면

- 시작 화면과 설정에 회원가입, 로그인, 비로그인 플레이 추가.
- 아이디·비밀번호·비밀번호 확인만으로 가입. 서버에서 계정 행을 자동 등록.
- 8~128자 비밀번호, 특수문자 필수 조건 없음. 입력 전 조건 표시, 표시/숨기기, 확인 불일치·중복 아이디·인증 실패 안내.
- 로그인 후 자동 저장. 저장 중, 실제 클라우드 저장 완료, 연결 실패·기기 보관, 기기에만 저장 상태 구분.
- 로그인 유지, 로그아웃, 비밀번호 변경, 운영자 초기화 코드 입력, 이전 복구키 계정 전환 추가.
- 일반 플레이어의 서버 URL·복구키 신규 발급·해시 계산·시트 수정 절차 제거. 이전 복구키는 기존 계정 전환 화면에서만 입력.

## 진행 보호

- 기기 저장을 서버·계정별로 분리. 로그아웃하면 비로그인 진행으로 이동.
- 로그인 시 서버 진행을 먼저 확인. 서버·동일 계정의 미전송 기기 진행·비로그인 진행이 다르면 챕터, 구간, 완료 구간 수, 플레이 시간, 저장 시각을 비교하여 선택.
- 서버 확인 실패를 빈 저장으로 간주하지 않음. 선택 전 자동 업로드 금지.
- 충돌은 revision 비교로 차단. 응답이 유실된 저장은 같은 requestId로 재시도.
- 진행 선택·가져오기·새 게임 시작 전에 최근 20개 복구 묶음을 계정별로 보관. 설정 → 기기 복구 사본에서 파일로 내려받기 가능.
- 기존 수동 저장·JSON 내보내기·가져오기 유지. 비밀번호 변경·세션 만료 시 현재 기기 진행과 미전송 요청 보존.

## 서버

- Google Sheets + Apps Script 유지. 사용자별 salt와 PBKDF2-HMAC-SHA256 600,000회, @noble/hashes 2.4.0 구현 포함.
- 세션은 24시간 또는 로그인 유지 30일. 서버에는 세션 원문 대신 해시 저장. 로그아웃·만료·비밀번호 변경·운영자 초기화에 따른 폐기.
- 소유자 확인 후에만 저장 접근. ID만 지정한 타 계정 접근 거부.
- 가입·로그인 제한, 고정 크기 시도 제한 표, ScriptLock 동시 작업 보호, 중복 아이디 거부.
- 기존 Players/Saves/Backups 및 원래 playerId 유지. 필요한 열·Sessions/AuthLimits만 추가. 중복되는 대소문자 아이디는 자동 합치지 않음.
- 밑줄 없는 운영자 함수: setupRpgSheets, resetPlayerPassword, backupRpgSheets, benchmarkPasswordHash.

## 배포

운영자가 cloud-config.js에 Apps Script 배포 URL을 한 번 등록합니다. 고급 URL 변경은 allowEndpointOverride=true인 개발 배포에서만 표시됩니다.

실행용·소스 ZIP에 Code.gs, 동일한 Code.txt, 운영자 README.txt, MIGRATION.txt, PLAYER_GUIDE.txt, RELEASE_NOTES.txt, VERIFICATION.txt 자동 포함. 원본 인증 코드는 apps-script/src/이며, 빌드할 때 한 파일의 Code.gs로 묶습니다. 비밀번호 해싱 코드는 게임 시작 시 다운로드하지 않습니다.

실제 Google 서버 URL은 아직 등록하지 않았습니다. 실제 Google 배포 검증 결과로 혼동하지 않도록 검증 문서를 따로 제공합니다.
